# data/

Drop 3–5 **public** clinical-trial protocol PDFs here (used for extraction + the gold set).

Good public sources:
- Journal-published protocols — *Trials* (BioMed Central), *BMJ Open*. These are open-access full protocols.
- ClinicalTrials.gov — some records attach the protocol/SAP under "Study Documents".

Keep it public-data only. Name them clearly, e.g. `nct01234567_protocol.pdf`.
